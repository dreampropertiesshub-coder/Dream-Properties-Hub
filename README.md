# Dream Properties Hub

Responsive static real estate blog website built with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — Home
- `about.html` — About Us
- `blogs.html` — Blog with live search, category filters and Load More
- `contact.html` — Contact form with browser validation
- `assets/css/style.css` — shared styles
- `assets/js/main.js` — shared interactions
- `assets/images/` — local SVG property illustrations

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. No build step is required.
3. Or run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Before publishing
- Replace `https://www.example.com/` canonical and Open Graph URL placeholders with your real domain.
- Replace `hello@dreampropertieshub.example` with your real email and update social links.
- Add actual Privacy Policy and Disclaimer destinations.
- Contact and newsletter forms are front-end demos only; connect a backend or form service to receive submissions.
- Blog cards are sample content. Read Article links currently point to a note on the Blog page; replace with published articles or CMS URLs.
- Verify project prices, approvals, RERA numbers and possession timelines with official sources before publishing.
- Google Fonts load online when available; fallback fonts work offline.
